# Example vault agents

Copy the paired `.md` + `.json` files into your Obsidian vault:

`03 - Resources/Agents/`

Then open the Flowti agent panel → **Manage agents** (or run `node .flowti/bin/main.mjs agent:dashboard-sync` from the vault root) so `agent-dashboard.json` and Agent World stay in sync.

- **FlowtiCursorPilot** — `ai.provider` is `cursor`; requires the Cursor CLI on `PATH` where Obsidian spawns the Flowti CLI.
