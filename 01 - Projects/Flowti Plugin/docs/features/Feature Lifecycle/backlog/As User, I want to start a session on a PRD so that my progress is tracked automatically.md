# As User, I want to start a session on a PRD so that my progress is tracked automatically

## Story

As a knowledge worker, I want to start a focused session on a specific PRD so that every doc I create, every frontmatter field I fill, and every backlog item I add during the session is automatically linked to that feature — building a documented trail of progress without any manual bookkeeping.

## Notes

- The session concept is inspired by the Development Lifecycle: "each session picks a PRD and brings it one step closer to the next stage"
- Sessions build knowledge incrementally — the user is encouraged to work with their documentation
- The session log becomes a narrative of how the feature evolved over time
