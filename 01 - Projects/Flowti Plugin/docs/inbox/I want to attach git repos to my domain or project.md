# Attach Git Repos to Domain or Project

When documenting a domain or project, the underlying source code repositories provide essential context. Linking git repos to domains would allow Flowti to surface commit history, branch activity, and code structure alongside domain documentation. This bridges the gap between architectural documentation in the vault and the living codebase.
