# Lifecycle Descriptions in Flowti

Domains, services, and flows go through lifecycle stages (draft, active, deprecated, retired). Flowti could provide a built-in way to define and track these lifecycle stages with visual indicators in the Event Catalog. Each entity's detail view would show its current lifecycle stage and transition history, making architectural governance visible within the vault.

**Note (C58):** The Feature Lifecycle domain delivers this for PRDs — 6-stage lifecycle (idea → done), gate checks, FRI scoring, stage transitions, and pipeline visualization. Entity-level lifecycle tracking (domains, services, flows) could extend this pattern in a future cycle.
