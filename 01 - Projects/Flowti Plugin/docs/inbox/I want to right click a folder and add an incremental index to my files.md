# Incremental Index for Folder Files

Users who organize files in numbered sequences (e.g., "01 - Introduction", "02 - Setup") need an easy way to re-index files after insertions or deletions. A right-click action on a folder would scan existing files, detect the numbering pattern, and re-apply sequential prefixes. This avoids manual renaming when reordering content within structured folders.
