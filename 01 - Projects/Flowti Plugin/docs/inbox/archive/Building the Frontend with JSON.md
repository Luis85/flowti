# Building the Frontend with JSON

Instead of hand-coding Obsidian UI components, a JSON-driven approach would allow defining views, forms, and layouts declaratively. A JSON schema would describe the component tree, and Flowti's renderer would interpret it into DOM elements. This enables rapid prototyping of new views and could power the Prototype Builder PRD's vision of citizen-developer-friendly UI creation.
