# PropertyDoc

A **PropertyDoc** documents a frontmatter property used across vault notes. Properties are the building blocks of the data model — they define what metadata fields notes carry and how those fields map to CSV columns.

PropertyDocs are managed through the Data Exchange Hub's Properties tab and auto-generated by the Data Dictionary Builder.

## Frontmatter Schema

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `type` | `"PropertyDoc"` | yes | Document type discriminator |
| `property` | string | yes | Frontmatter property name (e.g., `status`) |
| `description` | string | no | User-provided description |
| `csvColumns` | string[] | no | CSV columns that map to this property |
| `configs` | string[] | no | Config names that reference this property |
| `created` | timestamp | no | Creation date |

**File pattern**: `{docsRoot}/Properties/Property - {propertyName}.md`

## Managed By

- **Tab**: Properties (Data Exchange Hub)
- **Auto-generated**: Data Dictionary Builder scans vault frontmatter and creates PropertyDocs
