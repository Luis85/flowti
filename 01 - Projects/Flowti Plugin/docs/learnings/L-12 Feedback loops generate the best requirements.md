# L-12: Feedback loops generate the best requirements

The Session Focus Tools (Inc 11-12) weren't imagined during initial PRD drafting. They emerged from 5 increments of real usage — observing that a plain focus file link is insufficient. The lifecycle's Phase 10 → Phase 6 loop is how the best features surface.

## Pattern

- Deliver early, use the feature, observe gaps
- Post-release feedback (Phase 10) flows back to delivery planning (Phase 6)
- The best requirements come from real usage, not upfront analysis

## When to Apply

- Always — every feature delivery should include a feedback observation period
- Don't try to design everything upfront; plan for 2-3 feedback cycles
