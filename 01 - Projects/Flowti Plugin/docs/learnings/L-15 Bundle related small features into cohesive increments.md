# L-15: Bundle related small features into cohesive increments

Inc 8 delivered 7 capabilities (links, notes persistence, canvas, duration editing, template unlock, workspace button, context menu) as one increment because they were all "workspace enrichment". Individually each was too small for a full increment; together they formed a coherent theme. The key is thematic cohesion — not arbitrary bundling.

## Pattern

- Group small features by theme (e.g., "workspace enrichment", "preparation flow")
- Each feature should be individually too small for a standalone increment
- The bundle should tell a coherent story in the review

## When to Apply

- When multiple small features share the same code surface area
- When individual features would create overhead-heavy micro-increments
