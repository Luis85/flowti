# L-28: Process ceremony is knowledge graph fuel

## Context

The development process includes ceremonies like Definition of Ready, Definition of Done, cycle planning, and backlog refinement. Each ceremony produces artifacts (checklist results, decisions, retrospective notes) that become nodes in the knowledge graph.

## Observation

Each process step followed = one more link documented. Each step skipped = a gap in traceability. The knowledge graph does not grow from having good intentions — it grows from the discipline of following the process. The ceremony *is* the data entry mechanism.

## Takeaway

Process ceremony should be supported by the tooling, not imposed by willpower alone. Session preparation checklists, guided workflows, and auto-documentation reduce the burden of ceremony while ensuring the knowledge graph captures the full context. The goal is to make the right thing the easy thing.
