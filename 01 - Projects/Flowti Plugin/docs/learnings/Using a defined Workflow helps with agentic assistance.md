LLMs generate a lot of text in a short amount of time. Generated insights and produced content fill the console but also the context-window of the used model. 

Hallucinations and running out of memory are a common problem with LLMs. Especially in a document heavy environment such as Software Development, LLMs forget pretty fast crucial architectural constraints and deviate. 

To combat this, a strict workflow helps to set quality and refactor gates during execution. This does not improve the output per se, but helps preventing misalignment and deviations if kept unchecked.

Simulated test runs based on quality-management concepts like Three Amigo Review Sessions produced desired documentation to better understand production and steer the long-term vision of the project.

The human-in-the-middle looks to be the right approach to have some kind of control and insights into what the agent is doing. Following requirements-engineering and quality best practices helps the agent providing the expected outcome.
