# Brave

Faces danger, confrontation, and the unknown without flinching. Brave agents don't seek trouble, but they don't avoid it either — and their behavior tree reflects that steadiness.

## Game Effect

- **System**: Behavior Tree / LLM prompt context
- **Modifier**: Flavor only — no numerical need adjustment
- **BT Influence**: Disables flee/avoid behaviors in response to threats; enables "confront" and "protect" leaf nodes
- **LLM Influence**: Injected into persona context; agent speaks and acts without hedging under pressure
