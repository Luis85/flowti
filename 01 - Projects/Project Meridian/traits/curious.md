# Curious

An insatiable drive to explore, question, and understand. Curious agents seek out new information, investigate unusual events, and rarely pass an unexplained detail without probing it.

## Game Effect

- **System**: Behavior Tree / LLM prompt context
- **Modifier**: Flavor only — no numerical need adjustment
- **BT Influence**: Unlocks "investigate" and "ask question" leaf nodes; raises priority of explore behaviors
- **LLM Influence**: Injected into persona context; shapes conversational tone toward inquisitiveness
