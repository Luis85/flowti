# Hardy

Built for endurance. Hardy agents push through fatigue and hunger longer than most — not because they ignore their body, but because they're simply more capable of absorbing strain.

## Game Effect

- **System**: NeedsDecaySystem
- **Modifier**: hungerDecayScale = 0.8
- **Effect**: Hunger need decays 20% slower than baseline
- **BT Influence**: Threshold for "seek food" behavior triggers later than for other agents
