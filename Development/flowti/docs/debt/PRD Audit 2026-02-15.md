# PRD Audit — 2026-02-15

Comprehensive audit of all 26 Flowti IBDE Product Requirements Documents against the actual codebase (`src/`), existing tech debt (TD-01–TD-55), and cross-PRD consistency.

---

## Executive Summary

**26 PRDs audited** (14 done/open, 6 draft, 6 idea) against 164 source files and 55 tech debt items.

| Finding Type | Count |
|-------------|-------|
| PRD Gaps (missing sections, stale data) | 58 |
| Inconsistencies (PRD vs code) | 39 |
| New tech debt items identified | 22 (TD-56–TD-77) |
| Phantom events (PRD references nonexistent events) | 9 |
| Cross-PRD conflicts | 17 |
| Open questions requiring decisions | 30+ |
| Orphaned debt (no PRD owner) | 14 |

**Most critical findings:**
1. **API surface divergence**: Command Bus and Infrastructure PRDs describe methods, types, and events that don't exist in the codebase
2. **Stale metrics**: Event counts ("56+"), test counts ("679+"), category counts ("15"), tab counts ("8") are all outdated across multiple PRDs
3. **Phantom events**: 9 event types referenced across PRDs that don't exist in `FlowtiEventMap`
4. **Missing PRD domain**: 3 PRDs reference `prd.created`/`prd.updated` events — no PRD lifecycle domain exists
5. **Unacknowledged Hub dependencies**: 4 draft/idea PRDs depend on TD-49–TD-55 but don't reference them

**Action**: Update each PRD to use correct event names or remove phantom references.
