# As User, I want to see where each feature stands in the development lifecycle

## Story

As a vault maintainer managing multiple features, I want to see all my PRDs positioned at their current stage in a pipeline view so that I know at a glance which features need attention, which are blocked at quality gates, and which are ready to advance — without opening each PRD file individually.

## Notes

- The pipeline should show the 6 stages: idea → draft → approved → in-progress → review → done
- Gate readiness indicators (green/yellow/red) tell me whether a feature can advance
- This replaces the current workflow of opening feature folders and reading frontmatter manually
