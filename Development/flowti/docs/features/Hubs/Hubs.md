# The Hubs Features

Flowti will consists of different Hubs, all reflecting a core Domain of Flowti all revolving around the Event Catalog as Source of truth and Authority.

The Event Catalog should work as map to get to different hubs. From Products I can go into the product hub, improve my products, manage and design them. 

Each Hub gets documented trough the system by using the features.

The idea is, to reach the Product Hub if I am exploring Events with relation to the Product Tab. On the specific Hub I am able to create new ones, attach everything what the event catalog needs and further define and refine the records. Depending on the entity I can do Service Design, Requirements Engineering, Product Design and so on. All started from the respective hub.

Each Hub can start Domains to fill the event catalog, but they are also able to start new projects in the "01 - Projects" folder, or manage the Areas. A Hub is a dedicated workspace to manage a domain. Managing a domain inside a hub should also create Entity Docs like the Event Catalog.

Hubs are the main interaction point to work with the data and build relations between data-points. All feeding the Event Catalog but also feeding the knowledgraph.
