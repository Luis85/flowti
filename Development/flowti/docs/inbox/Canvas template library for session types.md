## Proposed Templates

1. **Domain Design**: Groups for Actors, Systems, Events, Services, Flows + Legend
2. **Sprint Planning**: Groups for Backlog, Sprint Scope, Risks, Dependencies
3. **Retrospective**: Groups for Went Well, Improve, Actions
4. **Brainstorm**: Empty canvas with Legend group only
5. **Flow Design**: Groups for Trigger, Steps, Decision Points, Outcomes
