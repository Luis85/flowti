Using a visual medium like the canvas makes it easy to convey an idea and invite for brainstorming.

Providing some structure or templates could open the opportunity to have predefined ingestion canvas, importing them and build the documentation out of that.

An Idea could be to have "Groups" as folders on the filesystem and the nodes of those groups be typed notes for the folders.

## Problem

Ingesting and connecting information requires navigating file trees and manually creating notes with correct frontmatter. This is tedious and disconnects the creative process from documentation.

## Proposed Solution

1. Canvas-as-ingestion: Provide preconfigured Canvas templates for different documentation tasks
2. Group-to-folder mapping: Canvas groups translate to vault folders
3. Node-to-note mapping: Canvas text/file nodes translate to typed notes
4. Visual-first workflow: Design on canvas → import to vault → documentation emerges automatically
