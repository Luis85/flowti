# Attach Multiple Git Repos to a Folder

Multi-repo projects need a way to associate several git repositories with a single vault folder. Flowti could ingest repository metadata (README, package.json, directory structure) and auto-generate documentation scaffolds for each repo. This would enable automatic documentation of mono-repo or poly-repo architectures from within Obsidian.
