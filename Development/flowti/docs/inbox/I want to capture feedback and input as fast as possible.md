I envision two action-ribbons
- add to input
- add feedback

After clicking on of those, I get just prompted with the title in a modal. By hitting Enter or clicking Ok, the Note gets created in a target folder.

I can then either work where I was or get redirected to the new Note.

I can configure the target and template for both.

I can also do the same with commands. the will be a third command which first asks for the type and then for the title, this is to provide quick-capture capabilities. For those there will also be the possibility to add custom types with custom templates and targets.

I can also open the type based quick-capture from an action ribbon
