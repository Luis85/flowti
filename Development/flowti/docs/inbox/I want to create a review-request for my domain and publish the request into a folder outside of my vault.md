# Domain Review Request Publishing

After documenting a domain, users need feedback from stakeholders who may not use Obsidian. A "Publish Review Request" action would export a domain's documentation (domain doc, services, events, flows) as a structured package to an external folder. Reviewers could annotate the export, and Flowti could re-import the feedback as inbox items.
