# Manage GitHub Repos from Obsidian

Switching between Obsidian and a terminal or GitHub Desktop for version control breaks workflow. A built-in git integration would allow users to commit, push, create branches, and open pull requests directly from within Obsidian. This is particularly valuable for documentation-heavy workflows where vault content and code evolve together.
