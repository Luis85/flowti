Besides Sessions, I also want to set timers. Either in the past or in the future. 

I want to set a point in time as start and another one as end to track what happened in between. 

The time-frames could span days or weeks. They should not automatically track but either be configurable or the user can attach notes to timers, or we can use the timers as query.

Timers in v1 are only user generated. Later timers can be set by other services, too. 

Timers can trigger events.
