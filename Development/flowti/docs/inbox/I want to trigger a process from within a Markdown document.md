# Trigger Processes from Markdown

Markdown documents describe workflows and processes in prose. Flowti could enable inline process triggers — special code blocks or callouts that, when clicked, start a session, run an import, or emit a custom event. This brings documentation to life by making described processes directly executable from the document that describes them.
