When designing I love to use a whiteboard to connect my ideas and thoughts. 

I want to create Canvas Sessions to emphasize the usage of mind-mapping and visualization. 

Starting a Canvas Session will open the Sidebar Session Monitor and the Session Canvas in main. 

The Canvas must be configurable with prepared Areas or Groups. For example, I want to design a new Domain. The preconfigured Canvas will then have ready made Groups to put Actors, Systems, Events, Services in it on the canvas ready to fill. This means I can also create Canvas Templates to preconfigure my Sessions. 

I can then later import this Canvas and the created Entities will be automatically generated based on their node type and settings.
