While developing an application new ideas and feedback will emerge constantly, according to the workflow from idea to solution we then create features and PBIs based on those. 

The traceability of shipped solutions back to an idea is already high. Now we need tools to prioritize our notes, based on easy metrics, weights, and ranks.

The current solution with Obsidian Bases and dedicated process descriptions is good but not very user friendly. 

With the sheer amount of available information in the vault I often forget where things are. 
I want to execute a well defined process which brings me from refined items to a prioritized backlog on multiple dimensions. 

I want to prioritize notes of same kind against either by scoring them, ranking them, sorting them, or empower them. 

I want to have dedicated prioritization sessions where I can choose the types of notes in a folder I want to prioritize against. Then I can asses those notes on a high-level where I see all in a sorted list based on the priorization. If I am unsure I want to drill down, maybe compare two notes against like an ELO System. 

I want to be able to make informed decisions on why and how I made my prioritization.
