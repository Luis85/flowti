[[Test Management]]

## Scope of a Testsuite

- Services
- Flows
- Features
- Use Cases

## Form of a Testsuite

A Testsuite can be attached to a domain, to a service, to a flow, to a feature, or to a use-cases.
Every Use Case must have a description of its functionality in the Gherkin format to be considered ready for development.
