
A Daily Note should capture and summarize what you have planned and worked on for the day.

They are the main source for content creation and should be used to outline ideas, branch out from the daily note in dedicated notes whenever you see fit. Using this technique, Ideas and their development get visible over time.

Using the daily note function provides journaling and documentation benefits, easily observable over time.

Daily Notes are a great tool to capture [[Daily Standup Meetings]] with your team.

To avoid becoming the daily-note a chore, try to keep your daily agenda as open and short as possible. Rather provide context to help kick-off filling the page.

## Prerequisites

- Create a Daily Note Template, skip to use the Standard Daily Note Template
- Create a Daily Notes Folder under Resources
- Configure Obsidian‘s Daily Note Plugin to use template and folder

## Procedure

- Open Todays Daily Note 
- Note down what you plan to work on for that day
- Use the Note as daily hub to reflect, plan, and outline new ideas
