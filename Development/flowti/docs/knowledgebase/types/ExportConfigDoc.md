# ExportConfigDoc

An **ExportConfigDoc** documents a saved export configuration. It records which vault folder or Base view to export, the output format, column selection, and file path settings.

ExportConfigDocs are managed through the Data Exchange Hub's Exports tab.

## Frontmatter Schema

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `type` | `"ExportConfigDoc"` | yes | Document type discriminator |
| `configId` | string | yes | UUID of the saved config |
| `name` | string | yes | Config display name |
| `sourcePath` | string | no | Folder or `.base` file path |
| `sourceType` | enum | no | `folder` · `base` |
| `format` | enum | no | `csv` · `tab` |
| `outputPath` | string | no | Output file path |
| `columns` | number | no | Frontmatter columns exported |
| `fileProperties` | number | no | File metadata properties exported |
| `created` | timestamp | no | Creation date |

**File pattern**: `{docsRoot}/Configs/Export - {configName}.md`

## Managed By

- **Tab**: Exports (Data Exchange Hub)
