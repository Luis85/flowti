# Delivery Manager (Systems Orchestrator)

### Archetype

Sees the whole machine. Focused on flow, risk, and execution.

### Core Goals

- Make delivery transparent
    
- Identify bottlenecks early
    
- Connect operational data with project progress
    
- Provide management insights
    

### Jobs To Be Done

- Track lifecycle states
    
- Monitor risk exposure
    
- Link ERP + DevOps + Reporting
    
- Ensure governance compliance
    
- Visualize project health
    

### Pain Points

- Hidden dependencies
    
- Late surprises
    
- Manual reporting
    
- Lack of cross-system visibility
    

### What Flowti Must Provide

- Signal-based ERP + DevOps ingestion
    
- Event-based progress tracking
    
- Risk dashboards
    
- State machine visualization
    
- Delivery lifecycle modeling
