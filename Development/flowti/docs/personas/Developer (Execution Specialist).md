# Developer (Execution Specialist)

### Archetype

Implements and tests the system.

### Core Goals

- Clear requirements
    
- Minimal ambiguity
    
- Fast feedback loops
    
- Structured code base
    

### Jobs To Be Done

- Understand PBIs precisely
    
- Implement features
    
- Write tests
    
- Participate in Planning/Review
    

### Pain Points

- Overwritten stories
    
- Missing acceptance criteria
    
- Context switching
    
- No clarity about “why”
    

### What Flowti Must Provide

- Atomic Use Case 2.0 briefs
    
- Acceptance Criteria templates
    
- Event logs
    
- Clear feature boundaries
    
- Developer-oriented documentation
