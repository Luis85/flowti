# The Integration Node (External System Persona)

This is important for Flowti.

Signals will connect to:

- Azure DevOps
    
- Epicor Prophet 21
    
- Microsoft 365
    
- Shopify
    

These are not users — they are **actors in your event system**.

You should model them as:

> System Personas

Attributes:

- Data format
    
- Sync frequency
    
- Authority level
    
- Conflict rules
    
- Signal direction (receive / send / bi-directional)
    

This will become foundational for your Signal PRDs.
