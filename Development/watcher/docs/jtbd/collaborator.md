# Jobs to be Done: The Collaborator (Chris)

> Persona: [The Collaborator](Development/watcher/docs/personas/Collaborator.md) | Journey: [Journey 4](../journeys/journey-4-share-and-collect-feedback.md)

## Jobs

| Job | When I… | I want to… | So that… |
|-----|---------|------------|----------|
| **Share drafts** | finish a draft in Obsidian | have it synced to the shared team folder automatically | colleagues can review it without me sending files around |
| **Receive feedback** | a colleague edits a shared file in Word or VS Code | have their changes pulled back into my vault | I see feedback inside Obsidian where I do my writing |
| **Preserve both versions** | edit a file at the same time as a colleague | have the conflict resolver create a renamed copy | neither version is lost — I can merge manually |
| **Ignore lock files** | a colleague opens a file in Word (creating `~$file.docx`) | have the lock file filtered out, never imported into the vault | my vault isn't polluted with Office temp artifacts |
| **Retry on locked files** | try to read a file a colleague currently has open (EBUSY) | have the plugin retry automatically after a short delay | I don't have to re-trigger the sync manually |
| **Catch up after absence** | return after a vacation | have reconciliation sync all changes colleagues made while I was away | I'm fully up to date without checking each folder |
| **Handle reorganizations** | a colleague moves or renames files in the shared folder | have orphaned vault copies cleaned up automatically | my vault mirrors the current shared folder structure |
