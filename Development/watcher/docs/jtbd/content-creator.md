# Jobs to be Done: The Content Creator (Max)

> Persona: [The Content Creator](../personas/content-creator.md) | No journey yet.

## Jobs

| Job | When I… | I want to… | So that… |
|-----|---------|------------|----------|
| **Capture on the go** | jot down an idea on my phone and it lands in OneDrive | find it in my desktop vault within minutes | no idea gets lost between devices |
| **Refine on tablet** | proof-read and restructure a draft on my iPad | have the polished version sync back to the desktop vault | I can continue working seamlessly on the desktop |
| **Single source of truth** | use the desktop vault for plugin specs and architecture docs | know the vault always has the latest version from any device | I never work from stale content |
| **Survive partial uploads** | start editing while OneDrive is still uploading a file | have the plugin wait for the file to stabilize before syncing | I don't import a half-written file into the vault |
| **Filter cloud noise** | OneDrive creates `.tmp`, `.partial`, or `file (1).md` conflict copies | have those artifacts filtered out automatically | my vault only contains real content |
| **Handle overlapping edits** | edit on my phone while the desktop is also open | have the newer version win (or both preserved via rename) | I never silently lose an edit from either device |
| **Catch up across devices** | open Obsidian on the desktop after a day of mobile-only work | have reconciliation pull in everything I wrote on phone and tablet | I'm instantly up to date without manual steps |
| **Consistent filenames** | create a file with accents or emoji on Android | find it matched correctly on Windows (NFC normalization) | I don't get phantom duplicates across platforms |
