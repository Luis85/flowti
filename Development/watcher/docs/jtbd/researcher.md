# Jobs to be Done: The Researcher (Alex)

> Persona: [The Researcher](Development/watcher/docs/personas/Researcher.md) | Journey: [Journey 1](../journeys/journey-1-import-external-notes.md)

## Jobs

| Job | When I… | I want to… | So that… |
|-----|---------|------------|----------|
| **Import new notes** | save a new file in my Dropbox research folder | see it appear in my Obsidian vault automatically | I don't have to remember to copy it manually |
| **Filter out noise** | sync a folder that contains temp files, downloads, or binaries | have only `.md` and `.txt` files imported | my vault stays clean and focused on notes |
| **Resume after offline** | open Obsidian after days away from my desk | have all new and changed files synced without a full re-scan | I'm up to date in seconds, not minutes |
| **Trust the sync** | let the plugin overwrite an existing vault file | know that it only overwrites when the source is genuinely newer | I never lose edits I made inside Obsidian |
| **Handle large files safely** | accidentally drop a 200 MB dataset into the source folder | have the plugin skip it gracefully instead of freezing | my vault and plugin stay responsive |
| **Cross-platform names** | create a file with accented characters on macOS | find it correctly matched on my Windows lab PC | I don't get duplicates like `café.md` and `café.md` |
