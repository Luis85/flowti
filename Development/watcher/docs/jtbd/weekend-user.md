# Jobs to be Done: The Weekend User (Jordan)

> Persona: [The Weekend User](Weekend%20User.md) | Journey: [Journey 3](../journeys/journey-3-catch-up-after-weekend.md)

## Jobs

| Job | When I… | I want to… | So that… |
|-----|---------|------------|----------|
| **Catch up on Monday** | open Obsidian after a weekend away | have all accumulated changes synced automatically on start | I'm ready to work without manual steps |
| **Skip unchanged files** | reconcile a folder with 500 files where only 5 changed | have the 495 unchanged files skipped instantly | reconciliation finishes in seconds, not minutes |
| **See progress** | wait while a large reconciliation runs | see a progress indicator (X of Y files, current mapping) | I know it's working and how long it will take |
| **Cancel if needed** | realize reconciliation is taking too long or syncing wrong files | cancel the operation cleanly and immediately | I can fix my settings before it processes everything |
| **Avoid double runs** | accidentally trigger reconcile while one is already running | get a clear notice instead of a second parallel run | I don't corrupt state or create conflicts |
| **Control what syncs** | have some mappings disabled or `reconcileOnStart` turned off | have only the enabled mappings with `reconcileOnStart` processed | disabled or paused mappings are respected |
